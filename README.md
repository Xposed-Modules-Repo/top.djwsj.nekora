# Nekora · 快手增强模块

面向快手标准版和快手极速版的 Android 增强模块。

[下载 APK](https://github.com/Xposed-Modules-Repo/top.djwsj.nekora/releases/latest) · [更新日志](CHANGELOG.md)

## 适配范围

| 宿主 | 包名 | 适配参考版本 |
| --- | --- | --- |
| 快手极速版 | `com.kuaishou.nebula` | 14.7.20、14.7.30.11804、14.7.40.11821、14.8.20、14.8.40.11936 |
| 快手标准版 | `com.smile.gifmaker` | 14.9.20.50799 |

以上为当前适配参考范围，不代表每个版本的全部功能均已完整实测，也不保证其间的所有小版本兼容。功能可用性还受动态插件、账号状态和设备环境影响，未列出的版本不作兼容承诺。

### 运行要求

- 本次 1.0.1 重发使用 `top.djwsj.nekora`；它与旧 `top.djwsj`、此前同版本的 `top.djwsj.nakora` 是不同应用，不能直接覆盖安装，旧模块 App 的数据不会自动迁移。
- 新旧包可以保留，但请在框架中只启用其中一个，避免对同一宿主重复注入。
- 安装下限为 Android 8.0（API 26）；实际可用系统版本还受宿主与框架限制。
- 正式 APK 仅提供 `arm64-v8a`，需要兼容的 64 位 ARM 设备和宿主进程。
- 使用支持 libxposed API 102 的框架，例如 Vector 2.2，并启用对应宿主作用域；旧 LSPosed 1.9.2 不支持此入口。
- 标准版、极速版与模块 App 的配置分别保存，开关不会自动相互同步。

## 功能

### 视频浏览与媒体保存

- 信息流视频广告过滤，自选运营弹窗拦截范围。
- 按点赞、收藏、评论数过滤视频与图文，支持短剧过滤及兜底保留。
- 显示视频发布时间、发布地和播放进度。
- 在分享面板查看、复制作品信息，保存视频、封面、所选图片及实况图；以宿主提供的有效资源和访问权限为前提。

### 防误触与界面个性化

- 点赞、收藏双击确认，屏蔽画面双击点赞，拦截长按点赞。
- 隐藏指定顶栏频道、底栏 Tab、整个底栏或拍摄加号；加号支持双击打开。
- 系统手势条显示控制及边到边显示。
- 侧边栏按组、按项隐藏，支持纯色、自选图片背景与透明度调整。
- 宿主设置页换肤，模块面板支持跟随系统、浅色和深色主题。

### 私信与评论

- 为已捕获的对方私信保留防撤回提示，支持消息推荐净化、通讯录引流内容净化和私信一键已读。
- 评论背景美化、详细日期时间，以及关键词、疑似引流、长度、IP 属地等过滤。
- 本地自定义评论：仅在本机显示，不会向平台真正发布。
- 极速版提供私信长按菜单的“消息数据”查看和字段复制；不作为标准版功能承诺。

### 配置与排障

- 桌面主页查看已安装宿主，访问发行仓库及交流渠道。
- 宿主设置页、分享面板中的模块入口，分类设置、账号信息查看及用户 ID 复制。
- 适配缓存重建，查找进度、阶段和耗时提示。
- 查找完成后显示总耗时，由用户确认是否重启，不自动重启。
- 崩溃日志捕获与导出。
- 应用内更新下载进度、取消和手动重试，安装包校验通过后再进入系统安装确认。
- 过滤同版、低版及无效版本更新提示。

### 签到与搜索辅助

- 每日签到辅助，按宿主登录态与当前有效任务执行。
- 搜索任务辅助：浏览搜索结果时处理当前有效任务，可选择延迟执行；不自动打开搜索页面。
- 需要本地开关及相应服务权限，任务结果以宿主实际判定为准。

### 分享与服务功能

- 固定、推送作品展示与播放状态回报。
- 在服务允许的用户、好友范围内推送作品或评论，以及对应接收展示。
- 需要配套服务、正常网络及相应账号授权，不代表任意账号默认开放。
